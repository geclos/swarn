# Greeting App

Tiny CLI used for swarn e2e tests.

Usage:

  bun run src/index.ts
  bun run src/index.ts alice
  bun run src/index.ts --name alice
  bun run src/index.ts --excited
  bun run src/index.ts --name alice --excited

Output:

  Hello, world
  Hello, alice
  Hello, alice
  HELLO, WORLD!!!
  HELLO, ALICE!!!
